Get started

Step 1 Create a GitHub OAuth App

Register a new OAuth application in your GitHub Developer Settings. Set the callback URL to http://localhost:3001/api/auth/callback.

Step 2 Clone & configure

Clone the repo, copy .env.example to .env, and add your GitHub OAuth credentials and an AI API key.

Step 3 Install & run

Run npm install then npm start. Open localhost:5173, sign in with GitHub, and pick a repo.

What is Repo Timeline?

Repo Timeline is a free, open-source developer tool that turns your GitHub commit history into a visual timeline. It shows merged pull requests and commits with significant line changes, displayed on a vertical timeline with AI-generated summaries that explain each change in plain English. Built for the era of vibe coding, where AI-assisted development produces rapid, large-scale code changes that are difficult to track through traditional commit logs.

How does it work?

Sign in with your GitHub account, select a repository and branch, and Repo Timeline fetches your merged PRs and major commits from the GitHub API. Each change is displayed as a dot on a vertical timeline. Click any dot to expand it and see an AI-powered summary that describes what changed and why in plain, non-technical language. You can toggle AI summaries on or off at any time.

Who is it for?

Repo Timeline is built for developers, engineering managers, and anyone who needs to understand the history of a codebase without reading diffs. It is especially useful for teams using AI coding assistants like Cursor, GitHub Copilot, or Claude Code, where codebases evolve quickly with large file changes that are hard to follow through conventional git logs.

What AI providers are supported?

Repo Timeline supports three AI providers for generating summaries: Anthropic Claude, OpenAI, and Google Gemini. Set the AI_PROVIDER environment variable and add the corresponding API key. Each provider has a sensible default model, and you can override it with AI_MODEL. The app works without any AI key configured — you just won't see generated summaries.
